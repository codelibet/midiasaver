# MidiaSaver

Baixe vídeos e imagens das principais redes sociais de forma rápida e gratuita.

O MidiaSaver permite salvar conteúdos públicos de diversas plataformas diretamente pelo navegador, sem necessidade de instalar programas ou criar uma conta.

Link da aplicação:
https://codelibet.github.io/midiasaver/

## Plataformas suportadas

- Instagram
- TikTok
- YouTube
- X (Twitter)
- Facebook
- Pinterest

## Como usar

1. Copie o link da publicação ou vídeo desejado.
2. Cole o link no campo disponível.
3. Clique em **Baixar**.
4. Aguarde o processamento e faça o download da mídia.

## Compatibilidade

O MidiaSaver funciona em navegadores modernos para:

- Computadores
- Android
- iPhone

## Limitações

Algumas restrições são impostas pelas próprias plataformas.

- Apenas conteúdos públicos podem ser baixados.
- Stories e conteúdos privados não são suportados.
- O YouTube pode limitar a qualidade máxima disponível para download.
- Eventualmente alguma plataforma pode deixar de funcionar temporariamente devido a mudanças em seus sistemas.

## Primeira utilização

O servidor utiliza hospedagem gratuita. Caso fique alguns minutos sem uso, ele entra em modo de espera.

Nessa situação, o primeiro download pode levar entre **30 e 60 segundos** para iniciar. Após esse período, os demais downloads acontecem normalmente.

## Aviso

Utilize o MidiaSaver apenas para baixar conteúdos que você possui autorização para utilizar, respeitando os direitos autorais e os Termos de Serviço de cada plataforma.
